# Personal Portfolio : นายสิทธิเมธา ศรีบุตรดา
> นักวิชาการสาธารณสุข (Public Health Technical Officer)

แฟ้มสะสมผลงานดิจิทัล (Personal Portfolio Web Application) ออกแบบด้วย Clean White Neumorphic UI รองรับทุกขนาดหน้าจอ (Responsive Web Design) 

## 🧭 โครงสร้าง 5 หมวดหมู่หลัก
1. 🎓 **หมวดที่ 1 : ประวัติการศึกษาและข้อมูลส่วนบุคคล**
2. 💼 **หมวดที่ 2 : ประสบการณ์ทำงาน & ทักษะความสามารถ** (พร้อม Interactive Skills Marquee)
3. 📜 **หมวดที่ 3 : ใบรับรองวิชาชีพและการฝึกอบรม** (12 ใบรับรองพร้อมระบบพรีวิวและป๊อปอัปขนาดเต็ม)
4. 💡 **หมวดที่ 4 : ผลงานและนวัตกรรม**
   - Green Hospital Portal (NCI Green Hub)
   - Fire Extinguisher EMS (Digital Inspection & Alert System)
5. 📸 **หมวดที่ 5 : รูปถ่ายและกิจกรรมการทำงาน** (17 ภาพถ่ายพร้อม Lightbox)

## 🚀 การติดตั้งและใช้งาน
สามารถเปิดไฟล์ `index.html` หรือรันผ่าน Web Server หรือเชื่อมต่อ Deploy บน Vercel / GitHub Pages ได้ทันที
